# cpp-text-browser
A simple C++ text-based web browser that connects to a server using socket programming and fetches webpage HTML content via HTTP requests.

A simple text-based web browser built using C++ and socket programming.
This application connects to a web server, sends an HTTP GET request, and displays the HTML source of the webpage in the console.

---

## 🚀 Features

- 🌍 Connect to web server using sockets
- 📡 Send HTTP GET request
- 📄 Fetch and display HTML source
- 🖥️ Console-based interface
- 🌐 Basic networking implementation

---

## 🛠️ Technologies Used

- C++
- Socket Programming
- TCP/IP Networking
- HTTP Protocol Basics
- Linux System Calls
